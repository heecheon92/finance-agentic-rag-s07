# ROI 1쪽 — 완성 예시 (강사, 10/8 실측)

> 6회차 과제의 완성 예시입니다. 측정값은 10/8 수업 폴더(49건, gpt-5.4-mini · nano) 실측이고, 가정값은 `scripts/roi.py` 의 기본값입니다. 자기 숫자와 자기 가정으로 바꿔 적습니다.
> 규칙 둘. **측정값과 가정값을 구분한다.** 측정값에는 파일 이름을, 가정값에는 "가정"이라고 적는다.

작성 2026-10-08  |  기준 결과 파일 `results/agentic.json` (40문항, gpt-5.4-mini · gpt-5.4-nano)

## 1. 측정값 — 문항 하나가 얼마인가

| 항목 | 값 | 출처 |
|---|---|---|
| 문항당 입력 토큰 | 11,625 (nano 6,813 + mini 4,811) | `results/agentic.json` usage, `make roi` |
| 문항당 출력 토큰 | 561 (nano 356 + mini 205) | 같음 |
| 문항당 비용 | 8.5원 ($0.0061) | 단가 기준일 2026-10-08 (developers.openai.com) |
| 재검색한 문항 비율 | 32.5% | `retry_count > 0` |
| 문항당 지연(평균 / p95) | 17.3초 / 33.8초 | `latency_ms_avg`, `latency_ms_p95` |

검색(임베딩·BM25·리랭커)은 로컬이라 API 비용이 0 이다. 돈은 LLM 호출에만 든다. 어느 호출이 큰지 한 줄: **입력 토큰은 nano 가 더 많지만(판정에 근거 6개 × 900자), 돈은 mini 의 출력 토큰(답변 본문)이 제일 크다. 출력 단가가 입력의 6배라서.**

## 2. 가정값 — 서비스 규모

| 가정 | 값 | 왜 그 값인가 |
|---|---|---|
| 일 질문 수 | 500건 | 가정. 상담사 20명 × 하루 25건. 1회차 디스커버리 노트의 현재 상담 건수로 바꾼다 |
| 월 영업일 | 22일 | 가정 |
| 환율 | 1,400원/$ | 가정(2026-10 기준 어림) |
| CPU 서버 1대 월 비용 | 300,000원 | 가정. 임베딩·리랭커·Qdrant 가 여기서 돈다. 4회차 실측 리랭크 4초/문항이면 일 500건에 CPU 로 충분 |
| 상담 건당 절감 시간 | 3분 | 가정. 약관 찾는 시간. 디스커버리 노트의 현재 처리 시간(8분)에서 |
| 상담사 시간당 인건비 | 25,000원 | 가정. 연봉 5,000만 ÷ 2,000시간 |

## 4. 외부 API 안 vs 내부망 GPU 안 (3년 TCO)

| 안 | 3년 비용 | 구성 | 얻는 것 / 잃는 것 |
|---|---|---|---|
| 외부 API | 14,178,528원 | API 93,848원 × 36 + 서버 10,800,000원 | 초기 투자 0, 모델 교체 쉬움 / 질문이 망 밖으로 나간다(마스킹 필수, 감사 로그에 원문 없음) |
| 내부망 GPU | 53,800,000원 | 구매 25,000,000원 + 운영 6,000,000원 × 3 + 서버 10,800,000원 (가정) | 망 안에서 끝난다 / 초기 투자, 작은 모델의 품질(별도 측정 필요) |

손익이 뒤집히는 일 질문 수: 약 1,897건 (선형 가정). 지금 가정(일 500건)에서는 **외부 API** 안이 3년에 약 3,960만원 싸다. 질문이 그 4배가 되기 전까지는 돈으로는 API 안이고, 그 전에 GPU 안으로 가는 이유는 돈이 아니라 망 분리 요건이다.

## 6. 이 숫자를 믿기 전에 (3줄)

1. **건당 3분 절감은 가정이다.** 순 효과의 거의 전부가 이 가정에서 나온다. 1회차 디스커버리 노트의 현재 처리 시간으로 바꾸고, 가능하면 상담사 두 명이 일주일 재서 넣는다.
2. **오거절률 10.5% 만큼은 상담사가 다시 본다.** 그 문항은 절감이 0 이 아니라 마이너스다(시스템을 보고 다시 찾는다). 절감에서 그 비율을 뺀다. 그리고 미답변형 2문항처럼 애초에 답이 없는 질문은 절감 대상이 아니다.
3. **단가는 2026-10-08 기준이고 바뀐다.** 출력 단가가 바뀌면 문항당 비용이 그대로 따라간다. 답변 길이를 700자로 제한하면 mini 출력 토큰이 줄어 비용의 큰 몫이 줄고, 그 효과는 `make agentic` 한 번(12분)으로 다시 잴 수 있다.
