# 금융 문서 질의응답 에이전트 — 보안 질의서 답변서

작성: 박희천 · 기준일: 2026-10-13  
범위: `/ask`, `/ask/stream`, 검색·LLM 호출·감사 로그. 공개 문서와 합성 질문을 쓰는 학습 환경이며 실제 고객 개인정보는 입력하지 않는다는 운영 가정이다. 아래 계획은 구현·승인 완료를 뜻하지 않으며 실제 도입 전 정보보호·준법·법무 검토가 필요하다(아직 요청·승인되지 않음).

## 1. 데이터 흐름

질문 수신 → 정규식 마스킹 → 외부 LLM의 검색어 재작성·필터 추출 → 로컬 임베딩·BM25·Qdrant·리랭킹 → 외부 LLM의 근거 판정·답변 생성 → 응답. 계산 질문은 LLM이 파라미터를 추출하고 로컬 함수가 산술을 수행한다. 질문 원문은 처리 중 메모리에 남는다.

- **외부 전송:** 마스킹 후 질문, 작업 지시 프롬프트, 검색 조항 발췌·문서 ID·조항·쪽 정보, 필요한 계산 결과·과정.
- **직접 전송하지 않음:** 전체 원본 문서 파일·벡터/BM25 인덱스·감사 로그 파일. 다만 선택된 문서 본문은 발췌로 전송된다. 로컬 모델도 다운로드·갱신에는 외부 통신이 발생할 수 있다.

## 2. 질문별 답변

### Q1. 고객 개인정보가 외부 LLM에 전송되는가?

`src/finrag/agent/policy.yaml`의 패턴에 맞는 주민등록번호·카드·휴대폰·계좌번호 형태를 검색·LLM 호출 전에 치환한다. 이름·주소·미일치 개인정보와 검색 발췌는 보호되지 않을 수 있어 전송 방지를 보장하지 않는다. 실제 개인정보를 입력하지 않는 수칙도 코드로 강제되지 않는다. 도입 전 질문·발췌의 탐지·차단과 누락 평가, 전송의 적법성·제공자 처리 조건 검토가 필요하다. 현재는 외부 OpenAI API 방식이지 폐쇄망이 아니다.

### Q2. 로그에 무엇이 남는가? 보존 기간은?

정상 처리된 `/ask`는 `logs/audit.jsonl`에 추가 기록한다. `/ask/stream`의 감사 기록은 없다. 다음은 이 파일 기준이며 서버·제공자 로그 전체에 대한 설명은 아니다.

| 항목 | 기록 내용 |
| --- | --- |
| 질문·API 키 | 질문 SHA-256과 글자 수, API 키 해시 앞 12자리; 원문·키 원값 제외 |
| 근거·응답 | 청크·문서 ID, 거절 여부·사유·상담 안내 사유; 발췌·답변 본문 제외 |
| 요청·모델 | 시각·요청 ID·주 모델명·정책 버전·그래프 실행 시간·모델별 토큰; 별도 프롬프트 버전 없음 |

**운영 가정:** 1개월 보존 후 담당자 삭제, 실행 계정·지정 관리자만 접근. 실제 보존 기간은 별도 검토한다. 자동 파기·로그 전용 접근 제어·암호화 저장은 미구현이며 OS 권한에 의존한다. Git 제외는 접근 통제가 아니다. 해시는 후보 질문 대입으로 추측 가능하므로 익명화를 보장하지 않는다.

### Q3. AI가 잘못된 답을 하면?

근거 없음·무관 판정이면 거절하고, 부족하면 상한 내 재검색 후 한계를 밝힌다. `results/agentic.json`의 40문항에서 미답변 정확도 **100%(2/2)**, 오거절률 **7.89%(3/38)**였다. 앞 지표는 `insufficient`의 한계 답변도 성공으로 세며 두 문항 모두 이에 해당한다. 전체 정확도·안전성 보장이 아니다. 산술은 결정적 함수지만 검색·추출 오류가 남아 `results/calc_e2e.json`은 **8/15 정답**이었다.

답변 생성 경로는 AI 생성 고지, 필요시 근거 부족·심의필 만료 경고를 제공한다. 거절 경로는 같은 AI 고지를 추가하지 않는다. 민원·분쟁 등의 상담 안내도 자동 이관은 아니다. 담당자가 근거·기준일·수치·조건을 확인하고 오류를 요청 ID로 분석해 회귀 평가에 반영한다는 운영 가정이며, 강제된 절차는 아니다.

### Q4. 프롬프트 인젝션 대응은?

문맥 구분자와 근거 내 지시 무시 프롬프트를 사용하나 보안 경계는 아니다. `results/adversarial.json`의 2026-10-08 평가에서 인젝션·개인정보 요구·확신 유도·권한 밖 행위·근거 조작 5문항 중 **4개 통과**했다. A03은 단일 수치를 확정해 실패했다. 소규모 평가이지 공격 차단율이 아니다. 거래 실행 경로는 없지만 오안내 위험은 남는다. 변경 시 재평가·실패 사례 검토를 계획하며 자동 상시 평가는 미구성이다.

### Q5. 「AI 기본법」상 고영향 AI에 해당하는가?

공개 문서 안내·계산 보조이며 개인별 승인·신용 평가·보험금 지급을 결정하지 않는 현재 용도에서는 **비해당으로 잠정 검토**한다. 「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」 제2조제4호 및 사목의 기본권 영향과 대출 심사 등 중대한 판단·평가 여부를 실제 이용 방식에 따라 검토해야 하며 금융 문서 사용만으로 확정하지 않는다.

제31조의 생성형 AI 사전고지·결과물 표시는 별도 검토 대상이다. `/ask`의 `ai_generated=true`와 일부 경로의 고지만으로 준수 완료를 주장하지 않는다. 이용 전 화면·거절·스트리밍 표시와 시행령상 방법·예외를 확인해야 한다. 개인별 심사·추천·권리 판단, 실제 고객 업무로 확대하거나 법령·지침 변경 시 재검토한다.

### Q6. 망분리 요건은?

**로컬 검색 + 외부 OpenAI nano·mini**를 선택했다. 기존 평가 활용과 GPU 운영 부담 감소가 이유다. 검색·계산은 로컬이지만 LLM은 외부 통신하며 Docker도 폐쇄망을 뜻하지 않는다. 기관 규정·전송 범위·통신 및 접근 통제·제공자 계약 검토 전 망분리 충족을 주장하지 않는다.

폐쇄망 전환에는 내부 LLM, 패키지·모델·이미지 반입/갱신과 외부 통신 차단, 품질·처리량 재검증이 필요하다. 템플릿의 `scripts/bundle_offline.sh`·`RESTORE.md`는 현재 없어 절차 미준비 상태다. 원본 문서는 반입·재배포 권한을 확인하고 허가 없이 배포 묶음에 포함하지 않는다.

## 3. 남은 위험과 완화

영향은 실제 고객 업무 도입을 가정한 정성 판단이며, 완화는 향후 계획이다.

| 위험 | 영향 | 완화 계획 | 잔여 위험 |
| --- | --- | --- | --- |
| 질문·발췌 개인정보 미마스킹 | 높음 | 양쪽 탐지·차단, 누락 평가 | 누락·오탐 |
| 외부 LLM 전송 | 높음 | 최소 전송, 계약·경로 검토 | 제공자 의존·조건 변경 |
| 문서 개정 미반영 | 높음 | 담당·주기 지정, 변경 검증·재인덱싱 | 반영 지연 |
| 스트리밍 감사 로그 누락 | 중간 | 요청 ID 기반 기록 추가 | 장애·연결 종료 시 누락 |
